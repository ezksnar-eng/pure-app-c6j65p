مشروع أندرويد مولّد من "تطبيق بيور"
=====================================

الطريقة 1 — GitHub (مجاناً وبدون برامج):
  1) ارفع كل محتويات هذا المجلد (ضمنها مجلد .github) إلى مستودع GitHub جديد.
  2) بعد الرفع يبدأ البناء تلقائياً من تبويب Actions.
  3) نزّل ملف app.apk من صفحة Releases بالمستودع.

الطريقة 2 — Android Studio:
  افتح المجلد كمشروع، وبعدها Build > Build APK(s).

ملاحظة: الـ APK موقّع بمفتاح debug مشترك للتثبيت المباشر على الجوال، مو للنشر بمتجر Play.
